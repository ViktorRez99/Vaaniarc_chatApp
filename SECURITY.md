# Security Policy

## Supported Versions

Currently, only the active development branch of VaaniArc receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for VaaniArc given its zero-trust, end-to-end encrypted nature. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the project owners directly. If you are an internal team member, bring this up immediately in our secure communications channel.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
