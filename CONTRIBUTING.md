# Contributing to VaaniArc

Thank you for your interest in contributing to VaaniArc!

**IMPORTANT:** VaaniArc is currently a **proprietary, closed-source project** under the "All Rights Reserved" license. 

## Internal Team Contributions
If you are an authorized team member of the VaaniArc project:
1. Ensure your local environment is set up according to the `README.md`.
2. Check out a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`.
3. Commit your changes using descriptive commit messages.
4. Push your branch and open a Pull Request (PR) against the `main` branch.
5. All PRs must be reviewed and approved by at least one other core team member before merging.

## External Contributions
At this time, we **do not** accept public pull requests, bug fixes, or feature additions from unauthorized external developers. Any unsolicited code modifications distributed or uploaded without permission exist in violation of our proprietary license.

If you have discovered a critical security vulnerability, please refer to our `SECURITY.md` policy for coordinated disclosure.
